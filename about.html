学习方法：把 106 讲真正学会

本站的学习科学设计 —— 费曼技巧 · 间隔重复 · 主动回忆

🧭 推荐学习路径：按 L1 → L2 → L3 顺序学

每个知识点页面都按同一顺序展开三层，难度逐级抬升。建议严格按顺序推进，不要一上来就啃数学：

  1. 🌱 L1 直觉层：一句话定义 + 生活类比 + 示意图。先看类比、建立直觉，再去记正式术语；示意图可以先自己预测结论，再看图验证。
  2. 🎬 交互动画：动手拖一拖滑杆、拖动曲线，观察均衡或曲线怎么变。参数变了结果怎么变，比背结论记得牢。
  3. 🌲 L2 推导层：图形推导 / 计算演示（考研深度）+ 考点提示 + 常见误区（❌误区 → ✅纠正）。做真题前务必过一遍误区清单。
  4. ⭐ L3 数学层：中高级数学表述默认折叠，零基础阶段可以直接跳过；备考考研与中高级课程时再展开细读。
  5. ✍️ 例题锁步：每讲 3 道题（L1/L2/L3 各一），答对当前题才解锁下一题；3 题全对，这一讲才记为「已完成」。

🗣 费曼技巧：先类比，后术语

费曼技巧（Feynman technique）的核心：如果你不能用最简单的话把一个概念讲给外行听，说明你还没真正懂它。本站把这套方法做进了页面结构——每个知识点都从生活类比开始，后给正式术语（L1 的「定义 → 类比」顺序）。

具体用法：学完一讲后合上页面，用自己的话向想象中的朋友复述「这个概念是什么 + 那个类比在说什么」；复述卡壳的地方，就是你没懂的地方，回到对应模块重看。能用买菜、排队、租房讲清楚的供求与弹性，才经得起考场上换一道题干的考验。

⏳ 间隔重复：用好错题本与「待复习」标记

遗忘曲线告诉我们：不在快要忘记时复习一次，学过的很快就会还回去。间隔重复（spaced repetition）就是按不断拉长的间隔重访学过的内容。本站把这个机制做成两样东西：

  • 错题本（首页）：做题时答错的题会自动收录，记录每道题的出错次数与最近错误时间；点「去重做」回到该讲重刷例题。
  • 待复习标记（学习地图）：最近 7 天内做错过的知识点，卡片会标为橙色「做错·待复习」并置顶提示——这是间隔重复给你排的复习提醒。

建议节奏：当天错题当场弄懂并重做一次 → 第 2 天再回错题本重做 → 第 7 天内再过一遍（卡片脱离「待复习」即说明已过窗口）。完全掌握、确认不再出错的知识点，可以用错题本下方的「清空错题记录」给清单减负——清空前请确认自己真的会了。

🎯 主动回忆：先做题，再看解析

重读笔记会让你「看着眼熟」，但眼熟不等于会。主动回忆（active recall）要求先凭记忆作答、再核对答案——检索本身就是在加固记忆。本站例题区的设计贯彻了这一点：

  • 先答后看：每道题先自己选，答完才展示解析；不要先翻上面的推导「找答案」，那只是复读，不是回忆。
  • 提示优先于答案：答错时页面只给针对性 hint（提示），先按提示再想一遍、重做一次，而不是直接看正确选项。
  • 锁步推进：答对当前题才解锁下一题，保证每一级（L1 概念 → L2 计算 → L3 考研难度）都是真会了才往上走。

📰 如何阅读「真实案例」

每讲的真实案例模块，是用现实事件印证教材结论。案例不是故事会——读的时候盯住四样东西：

  • 时间：事件发生在哪一年 / 哪个时期？经济结论往往依赖具体时点（如危机前后、政策切换期）。
  • 主体：谁在行动——央行、财政部、企业还是家庭？同一件事，不同主体的行为逻辑对应不同章节的模型。
  • 关键数据：案例中的数字一律与来源原文一致，注意单位与口径（同比 / 环比、名义 / 实际）。
  • 来源链接：每条案例末尾附统一格式的引用（[作者或机构, 年份, 《来源名》, 标题] + 链接），点开即可核对原文——这也是学习「证据从哪来」的示范。

读法的正确顺序：先自己用本讲模型猜一猜「现实里应该发生了什么」，再去读案例事实，最后对照案例解释检验自己的推理。

🔬 如何阅读「前沿进展」

前沿进展模块展示教材结论在研究前沿被补充、修正或挑战的地方。读前沿只看两件事：结论的边界与出处。

  • 默认折叠：前沿内容收在可折叠区块里，学完 L1/L2 再展开，避免初学阶段被争议扰了基本直觉；展开方式：点击区块标题。
  • 「学界尚有争议」标签：出现这个标签，表示该结论在学界存在对立观点，页面会同时呈现争议点与对立面——请把它当作「开放问题」而不是定论来记，考试论述题里能写出对立两面反而是加分项。
  • 结论边界：注意前沿研究的适用条件与样本范围（哪个国家、哪段时期、什么假设），教材结论往往是在更理想化的假设下成立的。
  • 出处可核验：每条前沿都附公开可访问的引用（工作论文页 / 期刊摘要页 / 机构报告），点击链接即可查证原文；查不到可靠来源时，本站会明确标注「暂未纳入」，绝不编造。

📚 内容基准与说明

本站教学内容以上列教材的共识内容为基准：

  • 曼昆（N. Gregory Mankiw）《经济学原理》（Principles of Economics）
  • 曼昆（N. Gregory Mankiw）《宏观经济学》（Macroeconomics）
  • 高鸿业《西方经济学》
  • 范里安（Hal R. Varian）《微观经济学：现代观点》（Intermediate Microeconomics）

「真实案例」与「前沿进展」的引用均来自公开可核验来源，以统一格式标注作者/机构、年份、来源名、标题与链接；数学记号使用纯文本写法，不依赖任何外部服务。学习进度与错题记录仅保存在你自己的浏览器本地（localStorage），不会上传。
